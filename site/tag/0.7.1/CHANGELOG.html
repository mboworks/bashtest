bashtest 0.7.1

0.7.1

  • Keep test execution properties, including test.no-sandbox, on the outer test
    without forwarding them to generated binary launchers.

  • Stream stdout/stderr live while capturing JUnit output without losing shared
    test state. Write provisional active-function reports for interrupted runs,
    drain capture workers before final results, and fail on capture/report errors.

  • Report source locations for failed expectations, including user helpers and
    subshells. Print golden-file diffs on stderr by default and capture them in JUnit
    failure reports, without duplicating diffs in verbose mode.

  • Retain scratch data for hook failures, aborts, invalid runner settings, and report
    errors under --keep-tmpdir=failure, including handled runner failures. Preserve
    original exit statuses and avoid cleanup of unresolved scratch paths.

  • Honor native Bazel test filters, sharding, and runner fail-fast. Validate filters
    and shard settings before hooks run, acknowledge shard support, keep reports
    local to each shard, and allow empty shards without masking an empty selection.

  • Preserve assertion failures across command substitutions, subshells, and waited
    background jobs. Add expect_success, expect_exit_code, and opt-in
    --strict-commands checking for unhandled command failures without discarding
    shared setup/test state.

  • Prevent skip requests from hiding failed expectations or nonzero returns.
    Reject invalid extended regular expressions in both positive and negative
    assertions instead of treating syntax errors as nonmatches.

  • Emit per-function JUnit XML for Bazel CI using XML_OUTPUT_FILE, with
    GoogleTest-compatible GTEST_OUTPUT and --gtest_output selection. Include
    assertion diagnostics, skipped cases, hook failures, and aborted functions.

  • Use mboworks_bzl 0.8.0 runfiles keys for helper executables and tool manifests.

  • Derive consumer fixture versions from the module and automate the README
    version update during release preparation. Test development/release version
    consistency and post-release version bumps.

  • Fixed the tools test's path expectation when bashtest is an external module.

  • Run the framework test suite as an external dependency in CI to catch
    root-workspace assumptions before BCR publication.

0.7.0

  • Automatically provision Bash and Unix utilities, including PCRE support, for
    bashtest on Windows x86-64 without system installation or PATH configuration.

  • Added named tools mappings that build executables for the test execution
    platform and export their resolved paths with their runtime runfiles.

  • Added Windows support with MSYS2 Bash using rules_shell runfiles resolution.

  • Preserved the existing source API while supporting manifest-only runfiles and
    renamed external module dependencies.

  • Fixed golden-file diagnostics and updates for manifest paths and filenames
    containing spaces or regular-expression characters. Tool errors do not update
    golden files, and short options preserve spaces in their values.

  • Fetch shallow publication snapshots and report complete site size with a 250 MB advisory budget.

0.6.1

  • Transferred the canonical repository from helly25/bashtest to
    mboworks/bashtest; future releases use the new mboworks_bashtest module
    name.
  • Added managed per-fixture scratch directories through test_tmpdir, with
    configurable retention and cleanup.

0.6.0

  • Added skip_test "${REASON}": marks the current test as skipped and reports the reason. Use
    skip_test "reason" && return to end the test body.
  • Added --no-skip, which turns every skip_test into a failure. For an environment that
    GUARANTEES the capability a test probes for, where a skip means the guarantee broke.
  • Fixed: a fatal abort inside a test no longer reports success. The EXIT trap's own last command
    became the script's exit status, so a failing run could exit 0. This repository's own test suite
    was dying at case 5 of 12 under set -u and still reporting PASS, hiding the seven that never
    ran.
  • Fixed: expect_contains / expect_not_contains aborted the shell when given an EMPTY array.
    bash 3.2 (which macOS ships) treats "${@}" and "${array[@]}" as unbound under set -u.

0.5.0

  • Added text-matching assertions:
    • expect_output_contains / expect_output_not_contains: literal substring checks.
    • expect_matches / expect_not_matches: extended regular expression (ERE) checks via bash's built-in [[ =~ ]] (no subprocess, so SIGPIPE-safe under set -o pipefail). ^/$ anchor the whole text, not individual lines.
    • expect_pcre_matches / expect_pcre_not_matches: Perl Compatible Regular Expression checks. These shell out to an external tool (grep -P, ggrep -P, pcre2grep, or pcregrep) via a here-string and fail with an actionable message when none is available.
  • Documented the cmd | grep -q SIGPIPE-under-pipefail pitfall in the README.

0.4.0

  • Renamed the module repo to helly25_bashtest and dropped the com_helly25_bashtest alias. The bashtest macro now resolves its runtime via a repo-relative Label, so it works regardless of the apparent repo name. Consumers must update load("@helly25_bashtest//bashtest:bashtest.bzl", "bashtest") (previously @com_helly25_bashtest).
  • Dropped legacy WORKSPACE support; the module is now bzlmod-only.
  • Extended the BCR presubmit support matrix: added Bazel 9.x and the Linux platforms ubuntu 22.04, Debian 12, and Rocky Linux 8 (alongside the existing ubuntu 24.04 and macOS).

0.3.1

  • Re-release of 0.3.0 (no functional changes).

0.3.0

  • Added explicit load of sh_library (needed for bazel 9).
  • Upgraded dependencies: bazel 9.1.1, bazel_skylib 1.8.2, platforms 1.0.0, rules_shell 0.6.1.

0.2.0

  • Added convenient target to print bashtest help bazel run //bashtest:bashtest_help which can be used with |pandoc -s -t man|man -l -.
  • Fixed description for flag '--test_filter'.
  • Added '--gtest_filter' which is an actual glob based filter (as opposed to '--test_filter' which uses posix regular expressions).
  • Correct support for space separated flag values.
